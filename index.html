Shared AI Disclosure

This section summarizes the use of AI tools across all course projects in accordance with the handbook. Generative AI tools were used by Group 09 - Ryzen9, and their use is disclosed here, on each assignment page, in each report, and in detail in AI_USAGE.md.

Tools used: ChatGPT (OpenAI), model GPT-5.6 — used by Tran Manh Thang and Hoang Kim Cuong; Claude (Anthropic), model Claude Opus — used by Phan Tan Loc.

Where AI was used. (1) This landing page and the skeleton of the three assignment pages — the HTML structure, the shared stylesheet, and the section layout required by the handbook — were drafted with AI assistance and then edited by the group. (2) While implementing the models and the training pipeline, AI was used as a reference for explaining concepts, reviewing code, and suggesting draft implementations; every suggestion was read, rewritten where needed, executed, and validated by the member who owns that component.

Where AI was not used. No experimental result, metric, figure, or table on this website was generated or estimated by an AI tool. Every reported number comes from running the group's own code, and is traceable to a checkpoint and a run directory in the repository.

Responsibility. All members understand and can explain every part of the submitted code and text. The group takes full responsibility for the content of this website, the repository, and the reports.
