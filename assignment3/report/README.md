# Assignment 3 M3 report and slides

- [Final report (PDF)](Ryzen9_A3_Report.pdf)
- [Presentation slides (PDF)](m3_slide.pdf)

This directory contains the published PDFs. The editable LaTeX sources and
their figure dependencies are maintained in separate, private source bundles.
To revise a document, extract its source bundle and compile its main
`.tex` file with pdfLaTeX. Keep the bundled logo and `figures/` beside the
source. Compile twice for references and page numbers.

The assignment webpage uses separate images under
`assets/a3-m3/` at the repository root.
